# Full project target stays binding

This matrix describes QC-C's scope; it does not replace FROZEN_DOD.md.

| Required capability | Evidence in this round | Still needed |
|---|---|---|
| Real frozen ~0.6B+ backbone | Same pinned Qwen3, 596,049,920 parameters | Target ~3B+, broader backbone capability checks |
| >=100k new facts, zero per-fact gradients | Shared value-code reader; no per-ID parameters | QC-C itself uses only four values and four heldout IDs in counterfactual worlds; population-scale diverse facts untested |
| No runtime knowledge-text tokens | Native reader path consumes numeric code | Learned reliable language-to-canonical-ID resolution |
| Direct, paraphrase, implicit-reference QA | Six noun wordings, direct IDs and fixed operator forms | Diverse natural language and implicit-reference resolution |
| 4/8/16-hop reasoning | Not tested | Composed actual knowledge operations |
| Unseen operator compositions | Five heldout forms, some overlap in truth-table semantics | Larger genuinely novel programs and value domains |
| Edit/revoke/restore/branch/snapshots | Local intervention replacement/off inverse | Integrated concurrent lifecycle state machine |
| Stale descendants cannot resurrect knowledge | No claim; decoder suffix recomputed | Real KV, JIT, generation-output and restart closure |
| <5% lifecycle overhead | Not benchmarked | Matched end-to-end measurement |
| >3x strong RAG speed at same quality | Simple text oracle only, no speed claim | Production-quality closest baselines, matching accuracy |
| >10x revision-aware JIT speed | Not tested | Compiler, caching and invalidation together |
| Two model ABIs | One Qwen decoder boundary | Second materially different real model ABI |
| Crash/tenant/snapshot safety | Not exercised by these reader probes | Integrate and retest previous runtime mechanisms |
| Distinct mechanism + Pareto benefit | Conventional affine/coupling ingredients | Joint quality, lifecycle and cost evidence |
| Paper + patent novelty audit | Focused ingredient review only | Full closest-work and claim-level comparison |

No percentage on this pilot can establish the overall target. We also do not
interpret a negative pilot as an impossibility result for the project.
