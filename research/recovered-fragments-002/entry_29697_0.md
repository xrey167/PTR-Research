# BT3: quotient projection of transferred relations

Sequential exploratory candidate, specified after partial BT1 (rebase2 39/40) and before observing BT2 QA outputs. Same new colors, pair, splits and gates as BT2. No hyperparameter search.

Idea: transferred pair residuals may contain lexical content from donor facts. Remove components lying in the span of donor color singleton directions, separately at each layer, K/V channel and token position. Each local vector concatenates the two KV heads (256 coordinates); six singleton directions span at most six dimensions. Selector-only singleton is deliberately excluded. FP64 SVD pseudoinverse with fixed relative tolerance 1e-10. No target test tensors, questions, gold or fitting of model parameters enter the projection.

Formula for local donor singleton matrix X (6×256), pair residual r: r_perp = r - (r X^+) X. Columns here are KV head coordinates. Candidate = target anchor + target singleton changes + projected donor pair changes. This is ordinary orthogonal projection, not itself a novelty claim. Removing lexical-span components is only a hypothesis; binding may occupy those same directions. Orthogonality proves a geometric property, not semantic disentanglement.

Compare with separately sealed BT2 unprojected hybrid and target1, plus freshly generated exact reference. Failure: <16/16 strict correct, any loss against exact, or no improvement over unprojected hybrid where it fails. All BT2 calibration/token-boundary rules retained. Timings from concurrent CPU execution cannot establish speed superiority.
