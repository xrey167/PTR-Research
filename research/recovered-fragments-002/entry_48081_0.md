not a new checkpoint selection rule or a completed comparison across all methods.

25/80 heldout answers. Its new-label instruction fails16/16 times:15 outputs are
the underlying stored color itself, one is B. Thus the failure is not uniformly
absence of value information; the reader often exposes the value but the output
operation/label contract is not followed.

14/16 are opposite. member013 succeeds16/16. This uneven profile motivates explicit
operation-form and truth-table reporting instead of the overall76.67% score.

single-boundary relative error is7.0876e-6, below1e-5. Across256 sequential edits,
maximum error reaches1.96591e-4, so the sequence requirement fails. Successful
single edits must not be described as stable arbitrary repeated lifecycle changes.

comparison, and the heldout questions are not added to training in QC-CR1.
