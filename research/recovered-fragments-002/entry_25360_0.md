# DS1: provenance repair and native decoder falsification

Preserve CC5–CC8 sources and seals. They declare Qwen3 revision
c1899de289a04d12100db3703e84a94a8a3df08b, whereas original model_attestation.json,
download_model.py and run_guarded.py specify
c1899de289a04d12100db370d81485cdf75e47ca. The latter agrees with upstream metadata.
Numerical roundtrips do not validate this declaration. A new compiler contract
must derive both model identities and weight hashes from pinned archival evidence,
include that evidence and executable source digests, and reject old roots.

Before any decoder evaluation: frozen Qwen3-0.6B, exact original weight SHA,
CPU FP32, eager attention, layer 23, injection once on last prefill token.
DS1 tests the literal additive use of the CC8 tensor. It does not test all
possible future adapters. No learning or threshold adjustment in this experiment.

Development: two generic boolean questions; validation: six independently named
records, each queried under both boolean worlds; two forms (direct and negated),
24 cases total. Random opaque record names carry no boolean information. Identical
questions recur with opposite knowledge. Modes: no injection, CC8 injection,
opposite CC8 injection, and explicit true-fact text oracle. 4 generated tokens,
greedy, no thinking, exact single-word Yes/No with termination required. All
model tokens and first-token logits for Yes/No retained. The candidate must
get all 24 correct and all 12 counterfactual pairs correct to pass this tiny
necessary diagnostic gate. Oracle quality reported independently. Failure says
nothing about feasibility of a learned universal semantic adapter.

Code and protocol sealed before validation. Failures and partial outputs retained.
No claims of 100k facts, 4/8/16-hop, second decoder, RAG superiority or novelty.
If installation/download/model preflight fails, retain BLOCKED status and do not
substitute a random model. Mathematical ABI roundtrip evidence remains separate.
