# QC-C2: nonlinear reader with conserved query coordinates

Recorded before C2 training and before C1 training outcomes. This is a separately
specified exploratory follow-up, not a test-driven selection of C1's best seed.

Same layer 23, rank-16 training-only basis, data splits, opaque ID/counterfactual
worlds, strict family-aware validation selection, 240 steps, Adam lr .02 and
seeds 17/29 as C1. Two-layer shared MLP (rank+4 input, 64 hidden GELU, d output)
projects its output orthogonal to the fixed query basis. Per-axis feature scale
is fitted only on bare training states. Last output layer starts at zero.
No per-installed-ID weights or gradients. This architecture has a different
parameter count/shape; comparison is equal optimizer budget, not equal FLOPs.

The projected output preserves the selected query coordinates in exact
arithmetic. Therefore an edit can recompute the old and new nonlinear correction
from those coordinates in the materialized state, without retaining the original
full query state. This is conventional additive coupling; no novelty claim.
Unlike C1's affine spectral cap, it has no global Jacobian conditioning bound.

Reuse C1's exact quality/paired-counterfactual gate. Full test generation covers
240 cases and all operation forms. Strict per-family performance matters more
than one aggregate. Numerical checks remain local at one decoder boundary.
Supplementary audit broadens the preliminary 2-query repair check to all 15
operation forms and retains the worst error across every repeated edit. Existing
C1 outputs remain unmodified. Performance timing is descriptive because the
independent C1 and C2 jobs may run concurrently on the eight-core CPU quota.
