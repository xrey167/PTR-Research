# QC-C1: counterfactual-conditioned invertible reader

Recorded before QC-C training. Exploratory protocol, not external preregistration.
The full frozen DoD is unchanged. This tests one interface gate only.

## Repair the QC-B design

Calibration/validation IDs in QC-B encode value and spec; their disjointness does
not remove this confound. Here use independently random opaque IDs. Every same
question/ID is evaluated in all four counterfactual payload worlds. No query
string contains the true payload; predicates necessarily name their candidate
values. Direct identity resolution is supplied by the harness, not learned.

Train: four opaque IDs, two wordings, all four worlds, ten familiar specs (160
cases). Validation: two disjoint IDs, two new wordings, same specs (80 cases).
Test: four further IDs, two further wordings, familiar plus five heldout specs
(240 cases). Wording selected per ID; all values share identical query text.
No claim of 100k evaluated facts. Counterfactual worlds are factual replacements
for the same identity, not independently sampled identities.

## Matched experiment

Fixed Qwen3-0.6B revision and frozen pretrained weights. Layer 23, rank 16 query
PCA fitted on bare TRAIN states only. Shared affine reader and spectral-bound
rho=0.9 reader use the same Q, zero bias, small identical initial weights and
same minibatch order for seeds 17 and 29. 240 Adam steps per run, learning rate
0.02; no per-ID trainable parameters. The bounded reader constrains full update
norm via orthonormal Q, not a feature-scaled Woodbury core.

Select checkpoints at steps 0/80/160/240 using strict complete validation answers:
maximize worst operation-family accuracy, then overall accuracy, then earliest
step. Greedy generation, at most 6 new tokens, correct whole label (optional one
period/exclamation mark) followed by an actual model terminator. This budget is
sufficient for the requested single-token labels and punctuation; it is not a
reasoning-chain budget. Train canonical label plus the correct chat EOS with
cross entropy. Avoid alternative-token/EOS mismatch in the training target.

Report all fixed runs; no selection by test. Test controls include no-memory and
true-fact-text oracle with the identical prompt. Text oracle is not strong RAG.
Wrong-value controls shift all value codes by one, scoring against both true and
shifted gold labels. Paired causal score counts only cases where this shift
changes the required label. Full generation covers every family, not 8 examples.

Gate: every familiar and heldout spec >=90% strict full-answer accuracy, paired
true+shifted correctness >=90%, and numerical repair max per-case relative error
<1e-5 with fresh/repaired next-token agreement. These are pilot gates and cannot
satisfy the full DoD on their own.

## Numerical and execution checks

Match cached suffix to complete backbone before training (max logit error <1e-5).
Check future target-token causality. Verify injected teacher-force execution vs
actual cached autoregressive second-token output on canonical first-token inputs.
Log bounded effective spectral norms and bias norms; bound applies to linear
Jacobian and does not erase rounding or imply semantic stability.

After fixed checkpoint selection test every value-to-value/off replacement on
real query states, plus 256 repeated replacements against independently fresh
states. Compare actual decoder output after boundary replacement. No downstream
KV state is repaired or revoked by this probe; the suffix is recomputed.
