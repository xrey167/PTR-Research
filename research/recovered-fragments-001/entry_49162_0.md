# QC-CR1: reconstructed, checkpointed joint interface experiment

The previous QC-C workspace was lost after an environment outage. Its observed
78/80 validation score is historical context only; the checkpoint is unavailable.
This is a fresh reconstructed experiment, not a byte-identical QC-C reproduction.
Original QC-B archive restored and all49 manifest entries verified. Full DoD unchanged.

Fixed pretrained Qwen3-0.6B revision c1899de289a04d12100db370d81485cdf75e47ca,
weight SHA f47f71177f32bcd101b7573ec9171e6a57f4f4d31148d38e382306f42996874b.
Frozen float32 backbone, CPU4threads, layer23, rank16 query-only training PCA.
Data/scope are in DATA_PROTOCOL.md: random opaque IDs and four counterfactual
worlds for every identical question. No entity-resolution or multi-hop test.

Methods: affine unrestricted, affine spectral rho0.9, nonlinear additive coupling
with projected output and64hidden units. Seeds17,29 for each;240Adam steps lr0.02,
canonical one-token label+chatEOS cross entropy. Training minibatch order uses a
separate RNG seed shared across methods, independent of initialization draw count.
No per-ID parameters. Same optimizer budget; not same FLOPs/parameter count.
One model process, all shared frozen-prefix batches reused. Loss must be finite.

Checkpoints at0/80/160/240 steps. Select by highest worst operation-family strict
full-answer validation accuracy, then overall, then earliest. Save current and
best weights, optimizer and RNG state every20steps; persist completed run results
before starting another. A resumed job verifies source hashes and configuration.
No checkpoint/seed selected by test. Test and shifted-value generations cover all
240cases and15families. Whole requested label, optional one punctuation mark,
then model EOS within6newtokens. Simple true-fact-text oracle and no-memory controls
are paired; text oracle is not strong RAG or a speed benchmark.

Causal score: both original and shifted answers correct on the144cases where
changing value to(value+1)%4 changes the required answer. Also report the complete
four-world truth-table score as an additional diagnostic, not a new selection rule.

Repair:15distinct real query states (one per family), all25old/new code pairs
includingoff. Compare independent fresh and repaired boundaries, actual recomputed
decoder logits, per-case maximum relative error. Sequence256edits, retain every
step's maximum and use the maximum acrossallsteps in the gate; compare final logits.
No prior downstreamKV is repaired: the decoder suffix is recomputed.

Execution gates: cached suffix vsfull model <1e-5maxlogiterror; future targettoken
cannot change earlierquery state (<1e-6); teacher-forced injected suffix vs real
KV autoregressive secondtoken logits <1e-3 (allows differingfloat32shapes, exacterror
reported). These checks are mandatory in the joint interfacegate.

Joint pilotgate: everyfamily strictaccuracy>=90%, pairedcausalaccuracy>=90%, all
singleandsequenceboundary errors<1e-5, fresh/repaired top-token agreement, execution
gatespass. Passing this small gate would still leave most fullDoD requirements open.
